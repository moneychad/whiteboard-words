# 白板词语

**Whiteboard Words** 是一个给家长使用的中文词语学习小工具：手机只负责生成方阵和保存记录，家长把词语抄到白板上，孩子看着白板学习，无需长时间盯着手机。

这是一个**单文件、零依赖、可离线使用**的网页应用。数据默认只保存在当前浏览器中。

## 功能特性

- **多种方阵**：支持 4 词（2×2）、9 词（3×3）、16 词（4×4）。
- **分级分类词库**：启蒙、幼小衔接、一年级、二年级，以及动物、食物、家庭、自然、动作与学习等主题。
- **自定义词语**：可输入自己的 2–3 字中文词语。
- **避免位置记忆**：一键随机重排，并尽量避免词语留在原来的位置。
- **避免跨词重复汉字**：同一方阵中的不同词语不会共用汉字，例如“小草”和“小羊”不会同时出现；词语内部天然重复的字不受影响，例如“爸爸”。
- **主题不足时自动补充**：当前主题无法组成方阵时，会加入同难度的其他主题，并在页面上明确提示。
- **家长手工记录**：学习结束后，按“认识 / 模糊 / 不认识”标记每个词语。
- **自动学习档案**：计算学习中、已掌握、记住又忘了、学习次数等状态。第一次标记“认识”即视为已掌握；“模糊”和“不认识”会进入当天复习。
- **复习安排**：根据每次结果安排复习，并在复习方阵中同样避免跨词共用汉字。
- **每日记录**：查看学习场次、认识率、词语档案和每次结果。
- **本地备份**：支持导出、导入 JSON，不需要账号或服务器。
- **手机友好**：三字词会随方格宽度自动缩小，在抄写和记录模式下都不会超出方格。

## 快速开始

### 方法一：直接打开

下载 [`index.html`](./index.html)，然后用现代浏览器打开即可。不需要安装、构建或联网。

### 方法二：本地静态服务器

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

### 方法三：部署到 GitHub Pages

项目根目录已经包含 `index.html`，可以直接启用 GitHub Pages：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/ (root)`，保存。
4. 部署完成后，手机访问 `https://<你的用户名>.github.io/whiteboard-words/`。

## 使用流程

1. 家长选择难度、主题和方阵大小。
2. 点击“生成词语方阵”。
3. 按方阵位置把词语抄到白板上。
4. 孩子只看白板学习。
5. 学习结束后，家长点击“完成抄写，开始记录”。
6. 点按词语切换“认识 / 模糊 / 不认识”，然后保存。
7. 在“复习”和“记录”页面查看后续复习与历史数据。

## 选词规则

- 不同词语之间不共用汉字，例如“小草”和“小羊”不能同时出现。
- 词语内部天然重复的字允许存在，例如“爸爸”“妈妈”。
- 当前主题无法组成指定数量的方阵时，自动加入同难度的其他主题。
- 自定义词语无法满足规则时，不会静默换词，而是提示更换词语或减少数量。

## 复习规则

| 本次结果 | 下次复习 |
| --- | --- |
| 不认识 | 当天 |
| 模糊 | 当天 |
| 认识 | 2 天后 |
| 连续两次认识 | 7 天后 |

第一次标记“认识”即视为“已掌握”；以前认识、后来变为模糊或不认识时，会标记为“记住又忘了”。

## 数据与隐私

- 学习记录使用浏览器 `localStorage` 保存。
- 没有账号、后端、广告或第三方统计。
- 词语数据不会主动上传到服务器。
- 清理浏览器数据、换浏览器或换设备前，请先在“记录”页面导出 JSON 备份。
- 数据模型已为后续白板照片和 OCR 结果预留字段，但当前版本不会上传或识别照片。

## 浏览器要求

推荐使用较新版本的 Chrome、Edge、Safari 或 Firefox。应用使用 `localStorage`、`structuredClone` 和 CSS Container Queries 等现代浏览器能力。

## 本地开发

项目没有第三方运行依赖，直接编辑 `index.html` 即可。

运行测试需要 Node.js 18 或更高版本：

```bash
npm test
```

也可以直接运行：

```bash
node --test tests/core.test.mjs
```
